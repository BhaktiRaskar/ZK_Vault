Working…
Why does the wrong password fail? AES-256-GCM produces a 128-bit authentication tag alongside the ciphertext. When you supply the wrong password, PBKDF2 derives a different AES key, so the tag computed during decryption doesn't match the stored one. SubtleCrypto raises OperationError before releasing any plaintext — zero information leaks.
Supported format: ZKCV v1 and v2 containers (downloaded via the "⬇ .enc" button above). Each container embeds its own salt and IV in its header, so no server connection is needed to decrypt. Files encrypted by other tools won't have this header and cannot be opened here.

YOUR PRIVACY, STEP BY STEP

How It Works

Your files are transformed on your device. Only encrypted data travels to the cloud.

01 · Select a file

Choose the file you want to protect on your device.

02 · Encrypt in browser

A random salt and nonce derive and protect an AES-256-GCM key locally.

03 · Upload ciphertext

The server receives the encrypted file and non-secret salt and nonce, never your password or key.

04 · Download & decrypt

Download the encrypted file and decrypt it in your browser with the correct password.

Files are encrypted before upload The backend never receives your password or encryption key The correct password is required to decrypt
